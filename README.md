# ZeusaALT

**A fast, local-only account manager and multi-client launcher for Windows (10 and 11).**

If you play Roblox on more than one account, ZeusaALT removes the sign-out, sign-in routine: add each account once,
see them all at a glance, and launch one or several into any game with a click.

- **Add each account once** through Roblox's own sign-in page. ZeusaALT keeps it signed in.
- **See every account at a glance:** online status, Robux, friends, and whether the sign-in still works.
- **Paste any game link** and launch one account, or several, into it.
- **Run several Roblox windows side by side**, and bring back any that crash.
- **Private by design:** your account data stays encrypted on your PC. There is no ZeusaALT account and no tracking.

## Download

Download the installer (`ZeusaALT-Setup-x.y.z.exe`) from the **Assets** list of the newest release.
